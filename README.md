
# Squad page
Dit is een overzicht van FDND jaar 1.

Beschrijving: Wij hebben een website gemaakt om kennis te maken met hva en onze medestudenten van FNDN jaar 1.

Gebruik: Op de homepage vind je alle lievelingsdieren van de studenten van FNDN jaar 1. als je op het dier klikt word je geleid naar het visitekaartje van de betreffende klasgenoot. Daar onder staat een ''button'', als je daar op klikt word door geleid naar de campuspagina.

Op de campus pagina vind je een plattegrond met alle gebouwen op de campus. Druk op eenen er komt informatie over het gebouw zoals eetgelegenheden, weetjes, routebschrijving enz.

Kenmerken: De website is gebouws met HTML, SC en Javascript

Index.HTML: Hier hebben we de HREF gebruikt, daarmee wordt het visitekaartje gelinkt naar de betreffende persoon. Naast dat hebben we ook class gebruikt bij dier en icoon. Zodat we in css makkelijk de grootte etc kunnen veranderen en alles gelijk is.
